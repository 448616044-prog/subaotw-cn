什么是敏感货？和普通货物有什么区别

「敏感货」并不是海关税则里的正式分类，而是两岸快递与物流行业对介于普通货物与禁运品之间那一大类货物的统称。这类货物本身可以合法运输，但因为牵涉到食品安全、公共卫生、动植物检疫、知识产权、无线电器材与电池安全等监管领域，在台湾出口申报和大陆进口清关两个环节都需要更细的品名、额外的随货单证和专门的报关通道。普通商业快递网点出于成本与风险考虑，往往直接拒收，或者要求寄件人自行承担退运、销毁的后果。

敏感货与普通货物的差别，实操上集中在三点：

第一，品名申报的颗粒度不同。普货可以写「日用品」「配件」这类笼统品名，敏感货必须写到可识别的层级。同样是茶叶，「茶叶」两个字是不够的，需要写成「乌龙茶（散装，500g/袋，无糖）」；同样是保健品，需要写成「乳清蛋白粉（罐装，2 磅，巧克力味）」。海关要据此判断税则号列、税率和监管条件，品名越模糊，被归类为「申报不符」的概率越高。

第二，需要额外的随货单证。食品通常需要成分表，保健品需要成分与规格说明，中药材需要产地与用途说明，化妆品需要品牌与规格信息，生鲜需要检疫相关文件，化工品需要成分浓度说明或安全数据表。这些不是走形式，而是查验时海关判断货物属性的直接依据。

第三，运输与仓储条件不同。含液体的化妆品要防漏，茶叶与药材要防潮，3C 产品要防静电防震，生鲜要冷链。普通快递的分拣体系依靠高速自动化，无法为单票货物提供这些条件，因此只能拒收。

理解这一点很重要：敏感货不是不能寄，而是要走对渠道、报对品名、带齐单证、做好包装。下面先给出速豹已经开通的 14 条敏感货专线入口，再逐条展开说明。

14 大品类逐个详解：能否寄、怎么申报、怎么包装

以下逐条说明每个品类的可寄范围、申报要素、包装要求、清关注意点和参考时效。注意：同一品类内部差异很大，最终能否承运以单票货物的实际属性和实时政策为准，寄前建议先与客服确认。

1. 食品寄大陆（零食、饼干、糖果、冲饮、调味品）

能否寄：大部分可以，是敏感货中资讯量最大的一类。申报要求：品名 + 主要成分 + 净含量 + 保质期 + 是否含肉、蛋、奶、坚果、蜂蜜等动物源或高风险成分，有原厂标签的一并拍照留存。包装要求：优先保留原厂密封包装；散装食品用食品级自封袋二次封装，外箱用五层瓦楞，膨化易碎食品四周留足缓冲，整体做防潮处理。清关注意点：含肉类、蛋类、乳制品、燕窝、新鲜水果的食品监管最严，多数需要检疫审批或不允许入境；纯素饼干、糖果、咖啡、冲饮、熟制坚果等风险相对低。数量以个人自用的合理数量为原则，整箱同款大批量会被按货物处理。参考时效：海运快线 4-7 天，空运 2-4 天。详见 食品寄大陆专线。

2. 茶叶寄大陆（乌龙、红茶、绿茶、普洱、茶包）

能否寄：可以，是敏感货里通关相对稳定的品类，也是两岸往来最常见的伴手礼。申报要求：茶类（乌龙/红茶/绿茶/普洱）+ 形态（散装/茶包/饼茶/袋泡）+ 净含量 + 是否含糖或花果等添加物 + 产地。包装要求：双层密封是核心，内袋加铝箔袋防潮防串味；饼茶用纸盒或铁盒外加气泡膜；外箱五层瓦楞，箱内填实避免晃动。清关注意点：茶叶按食品类监管，若含花果、柑橘皮等添加物可能涉及植物检疫；若附带茶具需分开申报，否则易造成整票申报不符；普洱饼茶建议保留产地与年份标识。参考时效：海运 4-7 天，空运 2-4 天。详见 茶叶寄大陆专线。

3. 保健品寄大陆（维生素、鱼油、蛋白粉、益生菌）

能否寄：可以，但需要逐项核对成分，属于申报要求较细的一类。申报要求：品名 + 主要成分及含量 + 规格（粒数/罐数/毫升）+ 品牌 + 是否含动植物提取物、鱼油、胶原蛋白、蜂胶等动物源成分。包装要求：保留原厂瓶罐并用气泡柱整体缓冲；玻璃瓶必须单独分格；液体或软糖形态先做防漏内袋再入箱。清关注意点：含动物源成分或濒危动植物成分的产品会被重点查验，涉及濒危物种及其制品的一律不受理；含麻黄碱、兴奋剂类成分的产品可能按药品或管制物处理；数量明显超出个人自用范围会被认定为货物，需按货物报关。参考时效：海运 4-7 天，空运 2-4 天。详见 保健品寄大陆专线。

4. 化妆品寄大陆（护肤、彩妆、洗护、香水）

能否寄：可以，但要在一般化妆品和特殊用途化妆品之间区分。申报要求：品牌 + 具体品类（面霜/精华/口红/洗发水/香水）+ 规格 + 是否含酒精、是否气雾罐、是否指甲油等易燃品、是否防晒等特殊用途。包装要求：原厂密封优先，瓶口加防漏内袋，玻璃瓶单独缓冲；气雾罐严禁挤压，需直立固定并留出透气空间。清关注意点：防晒、染发、祛斑美白、防脱发等特殊用途化妆品监管更严；香水、指甲油、气雾剂因含酒精或易燃溶剂，在运输和仓储上有额外限制；大批量无中文标签的成品通常需要按货物申报。参考时效：海运 4-7 天，空运 2-4 天，含危险品属性的件另行确认。详见 化妆品寄大陆专线。

5. 中药材寄大陆（饮片、原材、药膳料）

能否寄：可以，但必须先核对品种名录，是敏感货中需要提前确认比例最高的一类。申报要求：药材名（能提供拉丁学名或通用名最好）+ 药用部位（根/茎/叶/花/果）+ 形态（饮片/粉末/原材）+ 产地 + 用途 + 净含量。包装要求：防潮是第一要务，建议双层自封袋加干燥剂再套铝箔袋；粉末类先装密封罐再入外箱，避免扬尘和疑似不明粉末。清关注意点：涉及濒危野生动植物种及其制品的品种需要相应许可或不予受理，务必在寄件前确认；无标识的散装粉末容易被怀疑为管制物，建议保留原厂包装与购买凭证；毒性药材以及含毒性成分的复方需格外谨慎。参考时效：海运 4-7 天，空运 2-4 天。详见 中药材寄大陆专线。

6. 3C电子寄大陆（手机、平板、相机、耳机、周边）

能否寄：可以，是两岸寄递的高频品类。申报要求：品名 + 品牌型号 + 数量 + 是否含锂电池 + 电池容量（Wh 或 mAh）+ 是否全新。包装要求：原厂盒加气泡膜，整机外层套防静电袋；屏幕贴膜防刮；含电池的设备电极处贴绝缘胶带，避免运输中短路。清关注意点：电池内置且符合运输标准的设备可正常寄递；纯电池、充电宝、大容量动力电池按危险品管控，需要专门渠道；带无线发射功能的产品可能涉及型号核准；同一型号多台整机容易被认定为货物，需按货物报关。参考时效：海运 4-7 天，空运 2-4 天。详见 3C电子寄大陆专线。

7. 母婴用品寄大陆（奶粉、纸尿裤、洗护、喂养用品）

能否寄：可以，属于需要如实说明规格与产地的品类。申报要求：品名 + 品牌 + 规格 + 段数或月龄 + 材质；奶粉需注明段数、配方类型、产地、罐数和每罐克重。包装要求：奶粉罐最怕受压瘪罐，建议原箱加气泡柱整体加固；纸尿裤压缩体积后套防潮袋；奶瓶等玻璃件单独分格缓冲。清关注意点：婴幼儿配方奶粉监管较严，产地、段数、成分必须清晰；含液体的湿巾、洗护用品需做好防漏，渗漏污染同箱货物会连带影响整票；奶嘴、牙胶等入口类用品建议保留原厂密封。参考时效：海运 4-7 天，空运 2-4 天。详见 母婴用品寄大陆专线。

8. 生鲜寄大陆（冰鲜、冷冻、冷藏食品）

能否寄：部分可以，属时效敏感且检疫风险最高的品类，需提前预约舱位。申报要求：品名 + 通用名或学名 + 产地 + 状态（活/冰鲜/冷冻/冷藏）+ 净重 + 用途（食用或其他）。包装要求：泡沫箱加密封内袋加吸水垫，按温度需求配冰袋或干冰，外箱明显标注易腐与温度要求。清关注意点：生鲜属高风险检疫品类，多数新鲜肉类、蛋类、奶类、未加工水产及带土植物禁止入境或需检疫审批，实际可寄范围必须逐项确认；干冰用量与外包装标记需符合运输规则；生鲜一旦延误极易腐坏，请选择时效产品并了解相关保障条款。参考时效：空运 2-4 天，冷链专线以订舱确认为准。详见 生鲜寄大陆专线。

9. 酒类寄大陆（白酒、威士忌、葡萄酒、清酒）

能否寄：可以，但限制条件和税率都高于一般食品，属需单独确认的品类。申报要求：品名 + 酒精度 + 单瓶容量 + 瓶数 + 产地 + 包装形式（礼盒/散瓶）。包装要求：使用专用酒瓶气柱袋或泡沫格，逐瓶独立缓冲，瓶与瓶之间不接触，外箱标注易碎与向上方向。清关注意点：酒类在个人物品行邮税中适用较高税率档次，且多数渠道对单票酒精总量有上限；玻璃瓶破损风险高，寄前请确认破损责任的约定方式；无标识的散装酒、自酿酒通常不予受理。参考时效：海运 5-8 天，空运受限较多，以实际可订舱位为准。详见 酒类寄大陆专线。

10. 化工品寄大陆（胶水、清洗剂、树脂、助剂）

能否寄：需要先做属性判定，是专业门槛最高的品类，切勿按普货发货。申报要求：品名 + 主要成分及浓度 + 用途（工业/日化/实验室）+ 是否易燃、腐蚀、有毒、氧化，能提供的请一并提供安全数据表。包装要求：原厂密封容器外套二次密封袋，袋内放吸附材料，外箱标注方向与成分标签，重瓶居中、四周填实。清关注意点：凡列入危险化学品名录的必须走危险品资质与专门通道，普货渠道一律不受理；非危化工品也需备好成分说明以备查验；胶水、清洗剂、油漆、溶剂、高浓度酒精和成分不明的粉末是常见高风险件。参考时效：须以属性判定结果另行确认，不适用常规时效承诺。详见 化工品寄大陆专线。

11. 服饰寄大陆（成衣、鞋包、面料、配件）

能否寄：可以，属轻度敏感品类，主要风险在材质和数量。申报要求：品类 + 材质（棉/涤/羊毛/真皮等）+ 件数 + 品牌 + 是否全新带吊牌。包装要求：内套防潮袋，外箱瓦楞，重货适当压缩体积；真皮、皮草类需防潮防霉，箱内放干燥剂。清关注意点：涉及真皮、皮草、羽绒等动物源性材质的可能有检疫要求；大量同款全新带吊牌的服饰容易被认定为货物，需按货物报关并具备相应资质；无授权的仿牌、仿款一律不受理。参考时效：海运 4-7 天，空运 2-4 天。详见 服饰寄大陆专线。

12. 玩具寄大陆（模型、积木、娃娃、益智玩具）

能否寄：可以，需注意材质、电池与认证要求。申报要求：品类 + 主要材质 + 品牌 + 是否含电池、磁铁、液体或发声发光元件 + 适用年龄。包装要求：保留原厂彩盒，外加气泡膜；易碎部件单独缓冲；含水或油部件的玩具先做防漏处理。清关注意点：大陆对部分玩具品类实施强制性产品认证管理，批量进口需准备相应资料，个人自用合理数量一般按个人物品处理；含纽扣电池、磁力珠、吸水珠的产品风险较高，可能被要求补充资料；带品牌但无授权的仿牌玩具不予受理。参考时效：海运 4-7 天，空运 2-4 天。详见 玩具寄大陆专线。

13. 汽配寄大陆（零件、改装件、养护品）

能否寄：可以，但要区分新旧件和是否含油液、含电池。申报要求：品名 + 适配车型或零件号 + 材质 + 数量 + 是否含油、含电池、含气囊等安全部件。包装要求：重型件用木架或托盘加固；精密件做防震处理；含油件需控油并放吸附材料，确保无渗漏。清关注意点：旧件、二手件的监管要求与税率和新件不同，必须如实说明；含蓄电池、含气囊发生器或安全带预紧器等火工品的部件按敏感或危险品处理，需要专门渠道；单件超重超长的配件按大件物流计费与配舱。参考时效：海运 5-8 天，大件以实际配舱为准。详见 汽配寄大陆专线。

14. 五金寄大陆（工具、螺丝、锁具、建材配件）

能否寄：可以，重点是判断是否带刃、是否含危险品属性。申报要求：品名 + 材质 + 规格 + 具体用途 + 是否开刃。包装要求：重件用木架或托盘；带刃工具必须加装护刃套并固定，防止刺破外箱；散件分袋标注后再统一装箱。清关注意点：扳手、螺丝、钻头、合页、锁具等普通工具按普货或轻度敏感处理；属于管制刀具范围或可能造成人身伤害的利刃属禁运范畴；含易燃气体的气雾罐、强腐蚀性化学品需按危险品处理。参考时效：海运 5-8 天，重货以实际配舱为准。详见 五金寄大陆专线。

敏感货清关全流程：从台湾仓库到大陆签收

很多寄件人以为「交给物流公司就等着收货」，实际上敏感货的通关质量很大程度上取决于前端信息是否准确。完整链条分为六个阶段：

阶段一：寄件前确认。确认货物的品名、成分、数量、是否含电池/液体/动物源成分，准备好购物凭证或品名清单，并把这些信息完整告知客服。这一步做扎实，后面五个阶段基本不会出大问题。

阶段二：台湾出口申报。货物入仓后，按申报要素整理出口单证并向台湾海关申报出口。出口环节同样要求品名与实际货物一致，混装货物需逐项列明。

阶段三：运输。按品类与时效需求安排海运快线、海运经济线或空运。含液体、含电池、需冷链或有温度要求的货物在这一阶段会匹配不同的舱位与堆码方式。

阶段四：大陆进口清关。货物抵达口岸后进行进口申报，海关进行审单、计税、风险评估，必要时下达查验指令。查验分为机检和人工开箱，敏感货被抽中查验属于正常情况，如实申报的货物通常可以在补充资料后正常放行。

阶段五：缴税。若产生应缴税款，按清关模式结算。走双清包税渠道的，税费已包含在运费一口价内，由承运方统一结算；不走包税的，由收件人按海关核定金额缴纳。

阶段六：大陆派送签收。放行后转国内快递或专线派送，门到门签收。收件人签收时建议先验货，若外箱明显破损或与签收单不符，应当场拍照留证并联系客服。

「双清包税」到底是什么意思？「双清」指承运方同时负责起运地出口报关和目的地进口清关两端；「包税」指进口环节依法产生的税费已经纳入运费一口价，收件人无需再单独缴税。需要提醒的是，包税覆盖的是正常清关情形下依法产生的税费；如果因货物属性申报不实、夹带禁运品导致查验滞留、退运或销毁，由此产生的额外费用不属于包税范围，具体责任与费用承担以双方约定及承运条款为准。

敏感货申报要点与常见被扣原因

根据两岸线路的实操经验，敏感货在口岸出问题，绝大多数不是因为「品类不能寄」，而是因为申报信息与实际货物不匹配。以下是五类最常见的原因和对应的规避方法。

一、品名模糊。把「保健品」写成「礼品」，把「含乳饮料」写成「食品」，把「精华液」写成「化妆品」，都会被判定为申报不符。规避方法：按「品类 + 品牌或类型 + 关键成分 + 规格 + 数量」的格式填写，越具体越好；有原厂包装的，直接照标签抄写是最省事也最准确的做法。

二、申报价值不实。需要明确说明：低报价值属于违规行为，一旦被海关查实，可能面临补税、退运、罚款，并影响该收件人后续的通关信用记录，得不偿失。规避方法：按实际成交价格申报，并保留订单截图、发票或购物小票；赠品、样品也需注明来源并申报合理的市场价值，不要填零。

三、缺少成分说明。食品、保健品、化妆品、药材、化工品这几类尤其常见，海关无法判断货物属性时就无法完成归类，查验结果是要求补充资料或退运。规避方法：随货附上成分表或品名清单，粉末、液体、无标签的散装货物一定要提前说明来源与用途。

四、数量超出个人自用合理范围。同一品类同款 50 件、同一收件人短时间内多票同类货物，容易被认定为货物而非个人物品，需要按货物报关并提供相应资质。规避方法：以实际自用需求确定数量；确属商业批量发货的，提前说明并按货物清关模式准备资料，走对应的正规通道。

五、证照或批件缺失。需要检疫审批、强制认证、特殊用途备案的品类，缺件就无法放行。规避方法：寄件前把品名告知客服，由客服确认该品类是否需要额外批件；需要准备的尽早办理，不要等货物到口岸才发现缺件。

六、混装未分列。一箱里同时放食品、化妆品和带电池的电子产品，却只报一个品名，是最容易触发开箱查验的情况。规避方法：不同品类尽量分开装箱；确实需要混装的，逐项列明每一项的名称、数量和用途，不要合并概括。

敏感货包装规范：防潮、防漏、防震、外箱要求

跨境运输要经过多次装卸与长途颠簸，包装是敏感货能否完好到达的关键。通用原则如下：

防潮。茶叶、中药材、饼干、奶粉、纸尿裤、真皮制品对湿度最敏感。做法是：内层用自封袋或铝箔袋密封，放入干燥剂，外箱内壁加一层防潮膜或套防潮袋。海运柜内湿度高，防潮要求比空运更严格。

防漏。液体、膏体、含油件、含酒精件是渗漏高发品。做法是：瓶口先用保鲜膜或胶带缠绕加固，再装入密封内袋，袋内放吸水材料，最后居中放置、四周填实，避免瓶身在箱内滚动。

防震。玻璃瓶、电子产品、精密件、陶瓷茶具必须做缓冲。做法是：每件独立用气泡膜包裹，箱内空隙用气泡柱或珍珠棉填满，做到摇晃箱体时内容物不位移；重件放在箱底，轻件在上。

原厂密封优先。食品、保健品、化妆品、母婴用品尽量保留原厂密封包装和标签。原厂标签是海关判断货物属性的直接依据，拆散后分装会显著增加查验概率。确需分装的，请保留原标签复印件随货附上。

外箱要求。优先使用五层瓦楞纸箱，单箱重量建议控制在 20-25 公斤以内便于搬运；超重用木架或托盘加固并预留叉车作业空间；外箱六面胶带封实，接缝处做「工」字形封箱；去除旧面单和旧条码，避免分拣误读；外箱清晰标注收发货信息与必要的方向、易碎标识。

敏感货寄大陆税费说明

敏感货从台湾寄到大陆，税费如何计算取决于走哪种清关模式。常见的有三种：

一、行邮税（个人物品模式）。适用于个人自用、数量合理、价值在规定限值以内的进境物品。行邮税是把关税、增值税和消费税合并计算的一档综合税，现行税率分为 13%、20%、50% 三档：食品、饮料、家具、玩具、计算机等信息产品多适用 13% 档；纺织品及其制成品、一般电器、运动用品等多适用 20% 档；烟、酒、贵重首饰及珠宝玉石、高尔夫球具、高档手表、高档化妆品等适用 50% 档。行邮税设有免征额，应征税额在一定金额以下予以免征。具体税目归类、税率适用与免征额度，均以海关实际核定为准。

二、跨境电商综合税。适用于通过跨境电商渠道、符合单次与年度交易限值规定的零售进口商品。其特点是关税暂设为零，增值税和消费税按法定应纳税额的一定比例征收，因此综合税负通常低于一般贸易。常见品类的实际税负大致在 9% 到 24% 之间，具体取决于该品类是否涉及消费税及消费税税率。同样以海关实际核定为准。

三、一般贸易清关。适用于商业批量、超出个人物品或跨境电商品限值、需要正式报关的货物，按关税、增值税、消费税分别计征，需要收发货人具备相应资质并提供全套单证。

重要提示：本页所列的税率档次与税负区间为通行规则的说明性介绍，不构成任何税款计算依据。同一品名因成分、规格、用途、完税价格不同，归类和适用税率可能完全不同。实际应缴税额一律以海关核定结果为准。选择双清包税渠道时，税费已包含在报价内，寄件和收件环节均无需单独支付税款。

禁运品提醒：这些真的不能寄

敏感货不等于禁运品，但以下几类属于明确不受理的范围，请勿夹带。一旦夹带，整票货物都可能被扣留，寄件人需承担相应责任与费用。

一、易燃易爆及危险品。烟花爆竹、打火机燃料、液化气罐、高浓度酒精、汽油、油漆稀释剂、强酸强碱、氧化剂等。列入危险化学品名录的货物需具备危险品运输资质并走专门通道，普货与敏感货渠道一律不受理。

二、武器与管制器具。枪支弹药及其仿制品、管制刀具（匕首、三棱刮刀、弹簧刀等）、弩、电击器、催泪喷射器等。

三、毒品与管制药品。各类毒品、精神药品、麻醉药品，以及含有受管制成分而未取得合法处方与手续的药品。

四、侵权与违禁出版物。仿牌、假冒注册商标商品、盗版音像与软件，以及含有违禁内容的印刷品、音像制品与电子存储介质。

五、动植物及其制品。活体动植物、未经检疫审批的种苗种子、带土植物、标本，以及涉及濒危野生动植物种的制品（部分贵重药材、皮草、象牙、犀牛角、珊瑚等）。

六、检疫高风险食品。新鲜肉类及肉制品、蛋及蛋制品、未加工水产、鲜奶及部分乳制品、燕窝、新鲜水果、带土根茎类作物等，通常禁止入境或需检疫审批。

七、其他。货币及有价证券、贵金属原矿、无线电干扰设备、被有权机关依法禁止进出境的其他物品。

由于禁运清单会随政策调整而更新，且部分品类需要结合成分与用途判断，寄件前请务必使用 禁运品查询器 逐项核对。不确定时，直接把品名发给客服确认，比货物到口岸后被退运要省事得多。

常见问题 FAQ

1. 敏感货和普通货到底怎么区分？我这件算不算敏感货？

简单判断标准是看它是否涉及食品、药品、化妆品、动植物、电池、液体、粉末、磁性、品牌等任一监管要素。普通货物通常是无品牌、无源、成分单一的工业品或日用品，比如普通塑料件、书本、无电线的家居用品。凡是入口的、涂抹的、含电池的、带品牌的、动植物来源的，基本都要按敏感货处理。如果拿不准，把品名、成分表和实物照片发给客服，客服会在寄件前给出明确答复，避免货物入仓后才发现问题。

2. 台湾寄大陆敏感货一般几天能到？

常规情况下，空运专线约 2-4 天，海运快线约 4-7 天，经济海运约 7-12 天，均为门到门工作日估算，从入仓起算。需要提醒的是，敏感货的查验概率高于普货，一旦被抽中查验，时间会顺延；此外旺季舱位紧张、台风等恶劣天气也会影响船期。如果你的货物有明确的时间节点，建议在寄件时说明，客服会据此推荐更稳妥的时效产品，并预留缓冲时间。具体时效以订舱确认为准。

3. 双清包税是什么意思？收件人还需要交税吗？

双清指承运方同时负责起运地出口报关和目的地进口清关；包税指进口环节依法产生的税费已经包含在运费一口价内，收件人在收货时无需再单独缴税。要注意的是，包税覆盖的是正常清关情形下依法产生的税费。如果因货物夹带禁运品、申报信息与实物不符导致退运、销毁或额外仓储费用，这些不属于包税范围，责任与费用承担以承运条款和双方约定为准。

4. 食品和茶叶寄大陆有什么限制？一次能寄多少？

食品和茶叶本身可以寄，但有几个硬性边界：含肉类、蛋类、奶类、燕窝、新鲜水果的食品通常禁止入境或需要检疫审批，纯素饼干、糖果、咖啡、冲饮、熟制坚果、茶叶等风险相对低。数量上以个人自用的合理数量为原则，同款大批量会被认定为货物，需要按货物报关并具备相应资质。包装上要求密封防潮，散装茶叶请务必做双层封装。实际能否承运以单票确认为准，寄前请说明成分与数量。

5. 保健品和化妆品寄大陆需要什么证照？

个人自用、数量合理的货物一般按个人物品清关，不需要寄件人提供额外证照，但需要如实申报成分与规格，并保留购买凭证以备查验。需要注意的是：含濒危动植物成分的保健品不予受理；含麻黄碱、兴奋剂类成分的产品可能按药品或管制物处理；防晒、染发、祛斑美白、防脱发等特殊用途化妆品监管更严。如果属于商业批量进口，则需要按货物清关模式准备备案、标签和检验等资料，建议提前与我们确认。

6. 中药材能寄吗？哪些药材不能寄？

大部分常见药食同源类药材可以寄，但中药材是必须提前确认的品类。不能寄的主要是涉及濒危野生动植物种及其制品的品种，以及法律明确禁止进出口的品种，这类货物我们一律不受理。此外，无标识的散装粉末容易被怀疑为管制物，建议保留原厂包装与购买凭证；含毒性成分的药材及复方需格外谨慎。寄件时请提供药材的通用名、药用部位、产地和用途，客服会先核对品种名录再确认能否承运。

7. 含电池的产品能寄吗？充电宝和纯电池呢？

电池内置的电子产品，如手机、平板、耳机、电动牙刷，在符合运输标准的前提下可以正常寄递，申报时需要说明电池类型与容量。纯电池、充电宝、大容量动力电池属于危险品管控范围，普货和常规敏感货渠道不受理，需要走专门的危险品渠道并具备相应资质。含电池的设备要做好电极绝缘，避免运输途中短路。寄件时请务必主动说明是否含电池，隐瞒电池信息在安检环节被查出会导致整票退运。

8. 被海关查验或扣关了怎么办？会产生额外费用吗？

敏感货被抽中查验属于正常情况，不必过度紧张。如实申报的货物，通常按海关要求补充成分说明、购买凭证或用途说明后即可放行。我们的做法是安排专人与口岸对接，同步处理进度并指导你准备补充材料。费用方面，正常的查验配合不产生额外费用；如果查验后产生仓储、退运或销毁等费用，则按实际发生和责任归属承担。需要强调的是，因夹带禁运品或申报不实造成的后果由寄件人承担，这也提醒寄件前务必如实告知货物信息。

9. 一票能寄多少？会不会被认定为货物而不是个人物品？

会。海关判断是否属于个人物品，主要看数量、价值、同款重复度以及同一收件人的收件频次。同款数十件、单票价值明显偏高、短时间内多票同类货物寄给同一收件人，都有可能被认定为货物，需要按货物报关并提供相应资质。如果你的需求本身就是商业批量发货，建议在寄件时直接说明，我们会按货物清关模式为你匹配正规通道和报价方案，这比按个人物品申报被查出来再转为货物清关要高效得多。
